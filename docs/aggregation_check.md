## 1. 손계산 예제

파라미터 3개짜리 작은 모델, 클라 6 → 엣지 2 → 중앙.

규칙 (명세 "한 라운드의 실행 순서" 5·6번)

- 엣지 1차 집계: 담당 클라 모델을 **클라 표본 수**에 비례해 가중 평균
- 중앙 2차 집계: 두 엣지 모델을 **각 엣지에 속한 전체 표본 수**에 비례해 가중 평균
- 파라미터 자리마다 `Σ(n × w) / Σn`. 이미지를 합치는 것이 아니라 모델 파라미터를 평균함

### 1.1 클라별 모델값·표본 수

엣지 가중치가 제대로 걸리는지 보려고 표본 수를 일부러 다르게 둠 (엣지 총 400 vs 200).
실제 실험은 명세대로 클라별 이미지 수가 같음 (1,200장).

| 클라 | 엣지 | 표본 수 n | 모델 w |
|---|---|---|---|
| C1 | E1 | 100 | [1, 0, 2] |
| C2 | E1 | 200 | [2, 1, 0] |
| C3 | E1 | 100 | [4, 3, 2] |
| C4 | E2 | 50 | [0, 0, 2] |
| C5 | E2 | 50 | [2, 2, 0] |
| C6 | E2 | 100 | [2, 0, 1] |

### 1.2 엣지 E1 1차 집계 (총 표본 400)

| 자리 | Σ(n × w) | ÷ 400 |
|---|---|---|
| 1 | 100×1 + 200×2 + 100×4 = 900 | **2.25** |
| 2 | 100×0 + 200×1 + 100×3 = 500 | **1.25** |
| 3 | 100×2 + 200×0 + 100×2 = 400 | **1.0** |

### 1.3 엣지 E2 1차 집계 (총 표본 200)

| 자리 | Σ(n × w) | ÷ 200 |
|---|---|---|
| 1 | 50×0 + 50×2 + 100×2 = 300 | **1.5** |
| 2 | 50×0 + 50×2 + 100×0 = 100 | **0.5** |
| 3 | 50×2 + 50×0 + 100×1 = 200 | **1.0** |

### 1.4 중앙 2차 집계 (총 표본 600)

| 자리 | 400 × E1 + 200 × E2 | ÷ 600 |
|---|---|---|
| 1 | 400×2.25 + 200×1.5 = 1200 | **2.0** |
| 2 | 400×1.25 + 200×0.5 = 600 | **1.0** |
| 3 | 400×1.0 + 200×1.0 = 600 | **1.0** |

### 1.5 참고: 6개를 한 번에 평균해도 같음

| 자리 | 클라 6개 Σ(n × w) | ÷ 600 |
|---|---|---|
| 1 | 100 + 400 + 400 + 0 + 100 + 200 = 1200 | 2.0 |
| 2 | 0 + 200 + 300 + 0 + 100 + 0 = 600 | 1.0 |
| 3 | 200 + 0 + 200 + 100 + 0 + 100 = 600 | 1.0 |

엣지 평균에 엣지 총 표본 수를 다시 곱하면 Σ(n × w)가 그대로 복원되므로 2단계 결과 = 한 번에 평균.
모든 클라가 같은 공동 모델에서 시작해 전원 참여하고 엣지 집계 1번마다 중앙 집계를 하면,
**배정을 바꿔도 공동 모델은 같다** (명세 "비교 실험 해석"의 근거).
